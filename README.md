## About the Project

This project focuses on performing Exploratory Data Analysis (EDA) on the Males dataset. The analysis includes data loading, statistical analysis, data cleaning, missing value handling, data transformation, and visualization.

## Dataset

The dataset used in this project is the Males dataset.

Dataset Source: GitHub

- Data cleaning
- Data transformation
- Univariate analysis
- Bivariate analysis
