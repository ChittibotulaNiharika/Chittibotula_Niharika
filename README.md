## About the Project

This project focuses on performing Exploratory Data Analysis (EDA) on the Males dataset. The analysis includes data loading, statistical analysis, data cleaning, missing value handling, data transformation, visualization, clustering, dimensionality reduction, and regression analysis.

## Dataset

The dataset used in this project is the Males dataset.

**Dataset Source:** GitHub

## Phase 1 Tasks

- Loading the dataset
- Examining dataset information and displaying sample records
- Basic statistical analysis
- Checking and handling missing data
- Checking and removing duplicate rows
- Data cleaning
- Data transformation
- Univariate analysis
- Bivariate analysis
- Multivariate analysis

## Phase 2 Tasks

- One-dimensional statistical analysis
- Two-dimensional statistical analysis
- Three-dimensional data visualization
- Correlation analysis
- K-Means clustering
- Hierarchical clustering
- Cluster visualization and analysis

## Phase 3 Tasks

### Module 6: Principal Component Analysis (PCA)

- Preparing and standardizing numerical features
- Applying Principal Component Analysis
- Analyzing explained and cumulative variance
- Visualizing explained variance
- Reducing dimensionality using principal components
- Analyzing PCA feature loadings using a heatmap

### Module 7: Simple Linear Regression (SLR)

- Selecting experience as the independent variable and wage as the dependent variable
- Splitting data into training and testing sets
- Training a linear regression model
- Calculating the regression equation
- Visualizing actual values and the regression line
- Evaluating the model using MAE, MSE, RMSE, and R-squared
- Interpreting the results

## Conclusion

This project explores the dataset through statistical analysis, data visualization, clustering, dimensionality reduction, and regression. Phase 1 focuses on data exploration and preparation, Phase 2 applies statistical techniques and clustering methods, and Phase 3 uses PCA and Simple Linear Regression to reduce dimensionality and analyze the relationship between experience and wage. Together, these phases demonstrate the application of EDA and machine learning techniques to understand data and extract meaningful insights.
